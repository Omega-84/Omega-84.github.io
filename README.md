# Varun Nayyar - Portfolio

Personal portfolio website showcasing my projects, skills, and experience as a Data Scientist.

🔗 **Live Site:** [omega-84.github.io](https://omega-84.github.io)

## About Me

Data Scientist with 2+ years of experience building machine learning models, data pipelines, and analytics solutions. Graduated with MS in Business Analytics from Northeastern University (GPA: 3.8). Previously worked at Paisabazaar (India's largest credit marketplace) developing ML models for customer acquisition and risk assessment.

## Features

- 🎨 Neumorphism design with dark theme
- ✨ Interactive particle animation background
- 📱 Responsive layout (mobile-friendly)
- ⌨️ Animated typing carousel
- 🛠️ Skills section with technology logos
- 📅 Timeline for education & experience
- 💼 Project showcase with GitHub links
- 📧 Contact section with social links & CTA button
- 📊 Google Analytics tracking
- 🔄 Smooth scrolling & hover effects

## Tech Stack

- **Framework:** Jekyll
- **Styling:** SCSS
- **Animation:** Particles.js, AOS
- **Build:** Gulp
- **Hosting:** GitHub Pages
- **Analytics:** Google Analytics 4
- **Theme:** Based on [Neumorphism](https://github.com/longpdo/neumorphism) by Long Do

## Local Development

```bash
# Clone the repo
git clone https://github.com/Omega-84/Omega-84.github.io.git
cd Omega-84.github.io

# Install dependencies
yarn install
bundle install

# Run locally
gulp
```

Open `http://localhost:4000` in your browser.

## Customization

| File | Purpose |
|------|---------|
| `_config.yml` | Site settings, social links, about me |
| `_data/projects.yml` | Project listings |
| `_data/skills.yml` | Skills word cloud |
| `_data/timeline.yml` | Education & experience |
| `_sass/main.scss` | Colors and styling |
| `assets/particles.json` | Background animation |
